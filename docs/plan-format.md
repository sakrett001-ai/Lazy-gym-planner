# Файл плана Lazy Gym Planner (версия 1)

Свои планы выгружаются в JSON: «Свой план» → «Выгрузить». Файл открывается в приложении на любом
устройстве: «Свой план» → «Загрузить план» (файл или вставленный текст). Код — `src/js/11e-plan-files.js`,
тесты — `tools/plan-files.test.js`.

Файл — не резервная копия: в нём нет журнала, замеров, пульса и ответов о здоровье; из мест — только место плана.
Резервная копия восстанавливается в «Журнале»; если её загрузить как план, приложение так и скажет.

С версии 4.111 план несёт и то, от чего зависят его упражнения: мышцы, место с инвентарём, отметки «Что беречь» и
неделю цикла. У получателя план выглядит так же, как у отправителя, а свои отметки получателя действуют поверх отметок
плана. Тот же план можно отправить ссылкой (ниже).

## Пример

```json
{
 "format": "lazy-gym-planner/plans",
 "version": 1,
 "app": "4.10.0",
 "exported": "2026-10-09",
 "from": "Тренер Иван",
 "plans": [
  {
   "name": "Пн · Верх",
   "group": "Сила · неделя 1",
   "for": "Сергей",
   "note": "Без отказа, последний повтор с запасом",
   "goal": "strength",
   "format": "classic",
   "level": "mid",
   "groups": ["chest", "back", "triceps"],
   "place": {"name": "Зал у дома", "equip": ["bb", "bench", "db", "cable"], "dw": {"db": {"u": "kg", "v": [4, 6, 8, 10, 12.5]}}},
   "protect": ["knees"],
   "week": 1,
   "items": [
    {"id": "bbbench", "name": "Жим штанги лёжа", "sets": 4, "rest": 180, "reps": "3–5",
     "tempo": "3-1-1-0", "kg": [60, 62.5, 65], "note": "Пауза 1 с на груди"},
    {"id": "latpull", "name": "Тяга верхнего блока", "sets": 3, "rest": 90, "reps": "8–10", "kg": 50}
   ]
  }
 ]
}
```

## Поля

Файл:

| Поле | Обязательно | Значение |
|---|---|---|
| `format` | да | всегда `lazy-gym-planner/plans` |
| `version` | да | версия формата, сейчас `1` |
| `app` | нет | версия приложения, выгрузившего файл |
| `exported` | нет | дата выгрузки, `ГГГГ-ММ-ДД` |
| `from` | нет | от кого (до 40 знаков) |
| `note` | нет | общая заметка к файлу (до 400 знаков) |
| `plans` | да | список планов, до 50 |

План:

| Поле | Значение |
|---|---|
| `name` | название (до 40 знаков) |
| `auto` | ключ имени по умолчанию, если план назвало приложение (с версии 4.100.0): `my` — «Мой план», `plan:2` — «План 2», `day:0:up` — «Пн · Верх», `groups:chest,back` — «Грудь и спина», поправки `+copy` — «… — копия» и `#2` — «… (2)». Получатель видит имя на языке своей версии; если ключа нет или он незнакомый — имя из `name`. Прежние версии ключ пропускают. С 4.109 в ключе `groups:` может быть группа `adductors` («Приводящие»): версии до 4.109 её не знают и показывают `name`; ключи «Ног» и «Всего тела» без неё по-прежнему дают «Ноги и ягодицы» и «Всё тело» |
| `group` | программа: планы с одинаковой программой показываются вместе (например, дни одной недели) |
| `gauto` | ключ имени программы по умолчанию (с версии 4.100.0): `split:ul:1` — «Верх / низ · неделя 1» |
| `for` | для кого |
| `note` | заметка к плану (до 400 знаков) |
| `goal` | `strength`, `mass`, `cut` или `gentle` (бережно, с версии 4.11.0; более ранние версии пропустят цель и возьмут свою) |
| `format` | `classic`, `superset`, `circuit` или `static` |
| `level` | `beg`, `mid` или `adv` |
| `groups` | мышцы плана (с 4.111): коды групп — `chest`, `back`, `shoulders`, `biceps`, `triceps`, `forearms`, `abs`, `glutes`, `quads`, `hams`, `calves`, `cardio`. По ним — «Добавить упражнение» и подсказка «Пока не нагружены». Нет поля — мышцы по упражнениям плана |
| `place` | место плана (с 4.111): `name` (до 24 знаков), `auto` — ключ имени по умолчанию (`gym`, `home`, `street`, `homeband`, `place:5`), `equip` — инвентарь (коды из каталога), `dw` — наборы гантелей (`db`) и гирь (`kb`): `{"u": "kg" \| "lb", "v": [веса]}`. У получателя план открывается в своём месте с тем же инвентарём и теми же наборами; такого нет — добавляется новое место с этим именем, свои места не меняются. Нет поля — место, где получатель сейчас |
| `protect` | отметки «Что беречь», под которые собран план (с 4.111): `neck`, `shoulders`, `elbows`, `wrists`, `lumbar`, `disc`, `knees`, `kneeOp`, `achilles`, `hams`. Действуют в этом плане вместе со своими отметками получателя; в параметрах снимаются той же кнопкой. В ссылке на план этого поля нет |
| `week` | неделя цикла 1–4 (с 4.111), если план сохранён из недели программы: запас повторов и процент в строке нагрузки — как в этой неделе |
| `items` | упражнения по порядку, до 12 |

Упражнение:

| Поле | Значение |
|---|---|
| `id` | код упражнения из каталога; общий для русской и английской версий |
| `name` | название для человека; приложение его не читает |
| `sets` | подходы, 1–10 |
| `rest` | отдых, секунды, 0–600 |
| `reps` | повторы: `8`, `8–10` или по подходам через `/` — `10/8/6/5` (2–10 значений; если подходов больше, повторяется последнее число; прежние версии такую строку пропускают и берут повторы по цели); у удержаний и кардио повторов нет — время задаёт цель |
| `tempo` | темп: четыре числа или `X` через дефис, например `3-1-1-0` |
| `kg` | рабочий вес в килограммах: число или список по подходам (до 10 значений, до тысячных килограмма — вес, вписанный в фунтах, у получателя в фунтах тем же числом; версии до 4.100.0 округляют до 0,25 кг); если подходов больше, повторяется последний вес. Единицы, в которых вес показывается (кг или фунты), — настройка получателя, в файл не пишутся |
| `note` | заметка к упражнению (до 200 знаков) |
| `ss` | `false` — в формате «Суперсеты» упражнение не в паре со следующим, выполняется отдельно со своим отдыхом (с 4.111). Без поля — пары соседних упражнений по порядку |

Подходы, отдых и повторы приложение пишет явно — так, как их видно в плане у отправителя, поэтому у
получателя план выглядит так же, даже если у него выбраны другие цель и формат. В круговом формате
подходы и отдых задаёт круг, поэтому у упражнений их нет. В статодинамике повторы и отдых задаёт метод,
`sets` — число подходов (по три на серию), если его меняли.

## Как читается файл

* Добавляется всегда новыми планами; ничего не перезаписывается. Занятое имя получает номер: «Верх (2)».
* Имя по умолчанию (`auto`, `gauto`) пишется на языке версии получателя: план «Мой план» из русской версии в
  английской — «My plan». В файле без ключа (прежние версии) имя по умолчанию на русском или английском узнаётся
  по самому имени; имя, которое дал человек, остаётся как есть.
* Неизвестные упражнения пропускаются и перечисляются в предупреждении (по `name`).
* Значение вне допустимого пропускается, остальное в плане сохраняется; повторы одного упражнения убираются.
* Файл новее версии 1 загружается с предупреждением: незнакомые поля пропускаются.
* Один план без обёртки (`{"name": …, "items": […]}`) тоже читается.
* Файл больше 256 КБ не читается.

## Ссылка на план (с 4.111)

«Скопировать план», «Выгрузить» → «Скопировать текст» и «Поделиться» дают текст плана со ссылкой вида
`https://sakrett001-ai.github.io/Lazy-gym-planner/#plan=z…`. Код — `src/js/11m-plan-link.js`, тесты — `tools/plan-link.test.js`.

* После `#plan=` — весь план: `z` и base64url (буквы, цифры, `-`, `_`) сжатого deflate-raw JSON такого же файла плана, но без
  `app`, `exported`, названий упражнений и отметок `protect`; где браузер не умеет сжимать — `j` и тот же JSON без сжатия.
  Часть адреса после `#` не уходит на сервер: сервер не нужен и ничего не хранит.
* В ссылке нет данных о здоровье: отметок «Что беречь», ответов о здоровье, пульса, возраста, журнала, веса тела. Упражнения
  в ней — те, что видит отправитель, уже с заменами под его отметки и место.
* Ссылка ведёт на сайт, на котором сделана (GitHub Pages или Floot); из офлайн-файла — на GitHub Pages.
* Открытая ссылка показывает окно «План по ссылке» (что в плане) и «Добавить в свои планы» — как загрузка файла: планы
  добавляются новыми, ничего не перезаписывается. В самый первый запуск сначала идут вопросы, потом — окно плана.
* Текст со ссылкой целиком (или одна ссылка) вставляется в «Загрузить план» → «или вставить текст плана».
* Длина: тренировка — около 500–650 знаков, неделя из 5 дней — около 1100, свой план из 12 упражнений с весами по подходам
  и заметками — 1100–1700.
